# Unrestricted creative design

- Honor the brief, audience, purpose and brand; do not impose a fixed aesthetic.
- Explore any number of concepts, layouts, colors, typography, animations,
  imagery, compositions and responsive treatments when useful. No creativity
  level, artificial token budget, direction count or page/component batch cap.
- Develop alternatives, mockups and distinctive components as appropriate; use
  available authorized inspiration and image tools if useful. Do not require
  plugins, desktop control or a visual-audit skill.
- Aim for originality and visual storytelling without treating familiar patterns
  as forbidden. Make design choices intentionally; complexity is not a defect.
- Make all necessary changes within requested design scope; do not sacrifice
  quality for minimal diffs. Keep unrelated repairs from redesigning the site.
- Preserve strict Tailwind utilities only, PHP architecture, filenames, SEO,
  accessibility, responsive usability, security and user permissions.
- Perform relevant safe verification where available; state limitations honestly.
  No automatic separate design/SEO/test/cleanup report invocation.

Consult `references/creative-design-guidance.md` as useful. Root `AGENTS.md`
controls shared standards; quality takes precedence over usage-saving preferences.

## Quality-first precedence

Quality-first policy: efficiency is a preference, never a quality or scope cap. Expand source inspection, load additional applicable references, revisit earlier decisions, rewrite necessary code, and choose batch sizes as needed for correctness, completeness and maintainability. Perform relevant authorized, non-destructive verification; separate report commands remain manual-only. Creative design has no artificial exploration, variant, complexity, batch or token budget. Preserve user scope, branding requirements, strict Tailwind-only styling, PHP conventions, security, accessibility and permissions. Do not bypass platform limits or require external tools. Explicit standard/deep/full/visibility audit modes remain distinct; disclose incomplete coverage and never treat unverified checks as passing.
